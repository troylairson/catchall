How to enter a fraction

  1. Type the top number, press a b/c, then type the bottom number. 3 a b/c 4 → ¾
  2. For a mixed number, type the whole number and press a b/c before each part. 1 a b/c 3 a b/c 4 → 1¾
  3. a b/c ⇄ d/c switches answers between 1¾ and 7/4.

Keyboard: digits, Space for a b/c, + - * /, Enter, Backspace, Esc to clear.
