# catchall

- [`guitar-coach/`](guitar-coach/) — First Chords: a browser app that teaches electric guitar to total beginners (Vite + React + Web Audio). Live at https://troylairson.github.io/catchall/guitar/
- [`family-board/`](family-board/) — Family Board: a wall calendar and phone app for the family (React + Hono + SQLite), self-hosted on ZimaOS.
- [`fraction-pocket/`](fraction-pocket/) — Fraction Pocket: a pocket fraction calculator with an a b/c key (plain HTML/CSS/JS, no build). Deploys to https://troylairson.github.io/catchall/fractions/
